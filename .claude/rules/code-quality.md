# Code review

- Review against the approved requirements, architecture, design review, and implementation plan from the active story. Assess correctness, security, safety, error handling, test coverage, clarity, DRY, and dependency safety.
- Record structured findings in `code-review.md` with ID, area, severity or impact, recommendation, and resolution status. Distinguish actionable findings from observations and deferred items.
- Report findings before applying fixes and ask which findings the human approves; apply only those explicitly approved. If no actionable findings exist, ask for approval to proceed to verification.
- After approved fixes or approval to proceed, begin verification automatically.
